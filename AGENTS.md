# HareWare

An Astro app for [The Hare](https://theumdhare.com): the editorial board's
article tracker, and a generator that turns published articles into Instagram
posts.

## Agent skills

### Issue tracker

Issues live as GitHub issues on `zsrobinson/hareware`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
